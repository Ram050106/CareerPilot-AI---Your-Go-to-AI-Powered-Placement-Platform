## 📌 About The Project

**CareerPilot AI** is my second Full Stack Development project, built using the **MERN Stack (MongoDB, Express.js, React.js, and Node.js)**.

CareerPilot AI is a comprehensive placement preparation platform that helps students bridge the gap between learning technical skills and becoming industry-ready professionals.

The platform provides students with structured learning paths, modern career roadmaps, free and premium courses, resume-building resources, and mock interview practice to help them prepare for their dream jobs.

Whether someone is preparing for a Full Stack Developer, Frontend Developer, Backend Developer, or any other IT role, CareerPilot AI provides the resources and guidance needed throughout their placement preparation journey.

### 🎯 Our Mission

To make placement preparation more accessible, structured, and effective by bringing learning, skill development, and interview preparation together on a single platform.

## ⚙️ Installation & Setup

Follow these steps to run CareerPilot AI locally.

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- MongoDB
- Git

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project Directory

```bash
cd CareerPilot-AI
```

### 3. Install Frontend Dependencies

```bash
cd client
npm install
```

### 4. Install Backend Dependencies

```bash
cd ../server
npm install
```

### 5. Configure Environment Variables

Create a `.env` file inside your backend directory and configure the environment variables required by your application.

These may include:

- MongoDB connection string
- JWT secret key
- Server port
- Razorpay API credentials
- Any other API keys used in the project

**Important:** Never upload your actual API keys, passwords, or secret credentials to GitHub.

### 6. Run the Application

Start the backend server:

```bash
cd server
npm start
```

Start the frontend development server in a separate terminal:

```bash
cd client
npm run dev
```

*Use the actual scripts defined in your package.json files.*
